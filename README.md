# Watchtower

Admin-only login traffic monitor for OLC Database. Shows who signed in, failed and locked-out attempts, each member's IPs, and an IP location lookup.

Setup: run the files in `sql/` in order in the Supabase SQL Editor, then publish this folder with GitHub Pages. To watch another site later, add it to `config.js` and run the files in `sql/` on its project.
